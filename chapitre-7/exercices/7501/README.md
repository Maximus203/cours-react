# 7501 — Fiabilise trois comportements clés

Projet de départ pour l’exercice du chapitre 7. L’énoncé détaillé est remis séparément au format Word.

## Démarrer

1. Dans ce dossier, exécute `npm ci`.
2. Lance `npm run dev` et ouvre l’adresse locale donnée par Vite.
3. Travaille dans les fichiers `src/` indiqués par les commentaires `TODO(7501)`.
4. Vérifie le résultat dans le navigateur et lis la console avant de terminer.

Le starter fournit les trois comportements à tester : incrément du panier, formulaire e-mail obligatoire et réponse asynchrone simulée. Écris des tests d’interaction, fais passer la suite et vérifie qu’un test échoue si le comportement correspondant est retiré.

Le commentaire de travail invite à demander un indice ciblé ; il ne bloque pas techniquement un assistant. Tu restes responsable d’expliquer et de tester le code que tu écris.
