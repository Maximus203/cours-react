# 3302 — Corrige la case qui change de ligne

Projet de départ pour l’exercice du chapitre 3. L’énoncé détaillé est remis séparément au format Word.

## Démarrer

1. Dans ce dossier, exécute `npm ci`.
2. Lance `npm run dev` et ouvre l’adresse locale donnée par Vite.
3. Travaille dans les fichiers `src/` indiqués par les commentaires `TODO(3302)`.
4. Vérifie le résultat dans le navigateur et lis la console avant de terminer.

Reproduis le cas de la liste avec cases à cocher, puis remplace la clé d’index par l’identifiant de la tâche. Coche une ligne, supprime une ligne située avant elle et vérifie l’identité conservée.

Le commentaire de travail invite à demander un indice ciblé ; il ne bloque pas techniquement un assistant. Tu restes responsable d’expliquer et de tester le code que tu écris.
