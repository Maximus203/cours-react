# 2301 — Le bouton +2

## Démarrer

1. Dans un terminal ouvert dans ce dossier, exécute `npm ci`.
2. Démarre le serveur avec `npm run dev`, puis ouvre l’adresse locale indiquée par Vite.
3. Réalise la tâche dans les fichiers `src/` indiqués par les commentaires `TODO(2301)`.
4. Vérifie le résultat dans le navigateur et l’absence d’erreur dans la console.

Corrige l’action « Ajouter deux » pour que deux mises à jour successives ajoutent réellement 2, même lorsque React les traite dans le même événement.

Le détail des étapes et des éléments à vérifier se trouve dans le document Word associé.
