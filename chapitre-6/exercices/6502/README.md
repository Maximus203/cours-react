# 6502 — Choisis entre props, contexte et hook

Projet de départ pour l’exercice du chapitre 6. L’énoncé détaillé est remis séparément au format Word.

## Démarrer

1. Dans ce dossier, exécute `npm ci`.
2. Lance `npm run dev` et ouvre l’adresse locale donnée par Vite.
3. Travaille dans les fichiers `src/` indiqués par les commentaires `TODO(6502)`.
4. Vérifie le résultat dans le navigateur et lis la console avant de terminer.

Dans `DECISIONS.md`, compare props, état local, contexte et hook personnalisé pour le cas fourni ; implémente un choix minimal et vérifie qu’il ne crée pas un store inutile.

Le commentaire de travail invite à demander un indice ciblé ; il ne bloque pas techniquement un assistant. Tu restes responsable d’expliquer et de tester le code que tu écris.
