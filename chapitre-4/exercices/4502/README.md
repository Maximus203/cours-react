# 4502 — Conçois une expérience réseau robuste

Projet de départ pour l’exercice du chapitre 4. L’énoncé détaillé est remis séparément au format Word.

## Démarrer

1. Dans ce dossier, exécute `npm ci`.
2. Lance `npm run dev` et ouvre l’adresse locale donnée par Vite.
3. Travaille dans les fichiers `src/` indiqués par les commentaires `TODO(4502)`.
4. Vérifie le résultat dans le navigateur et lis la console avant de terminer.

Complète une fiche de profil distante avec rafraîchissement, gestion d’erreur réessayable et nettoyage. Justifie les dépendances de chaque effet dans `DECISIONS.md`.

Le commentaire de travail invite à demander un indice ciblé ; il ne bloque pas techniquement un assistant. Tu restes responsable d’expliquer et de tester le code que tu écris.
