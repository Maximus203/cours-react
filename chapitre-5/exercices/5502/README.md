# 5502 — Défends tes choix de navigation

Projet de départ pour l’exercice du chapitre 5. L’énoncé détaillé est remis séparément au format Word.

## Démarrer

1. Dans ce dossier, exécute `npm ci`.
2. Lance `npm run dev` et ouvre l’adresse locale donnée par Vite.
3. Travaille dans les fichiers `src/` indiqués par les commentaires `TODO(5502)`.
4. Vérifie le résultat dans le navigateur et lis la console avant de terminer.

Choisis un parcours différent, organise ses routes et rédige `DECISIONS.md` : route index, segment dynamique, lien de retour et traitement des accès non autorisés.

Le commentaire de travail invite à demander un indice ciblé ; il ne bloque pas techniquement un assistant. Tu restes responsable d’expliquer et de tester le code que tu écris.
