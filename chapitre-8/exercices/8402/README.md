1. Dans ce dossier, exécute `npm ci`.
2. Lance `npm run dev` et ouvre l’adresse locale donnée par Vite.
3. Travaille dans les fichiers `src/` indiqués par les commentaires `TODO(8402)`.
4. Vérifie le résultat dans le navigateur et lis la console avant de terminer.

Teste les états prêt, réponse partielle, fin, erreur et annulation avec la réponse simulée. Aucun test ne contacte un fournisseur réel.
