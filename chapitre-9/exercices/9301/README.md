# 9301 — Une route profonde tient au rechargement

Projet de départ pour l’exercice du chapitre 9. L’énoncé détaillé est remis séparément au format Word.

## Démarrer

1. Dans ce dossier, exécute `npm ci`.
2. Lance `npm run dev` et ouvre l’adresse locale donnée par Vite.
3. Travaille dans les fichiers `src/` indiqués par les commentaires `TODO(9301)`.
4. Vérifie le résultat dans le navigateur et lis la console avant de terminer.

Ajoute une route imbriquée `/ateliers/:atelierId` avec une page de détail fictive. Lance le build et la prévisualisation, ouvre directement `/ateliers/decouverte`, actualise la page, teste retour et navigation, puis distingue les rôles du routeur et du serveur statique.

Le commentaire de travail invite à demander un indice ciblé ; il ne bloque pas techniquement un assistant. Tu restes responsable d’expliquer et de tester le code que tu écris.
