# 1202 — Prévois une valeur par défaut sans modifier la prop

## Démarrer

Dans un terminal, exécute npm ci, puis npm run dev.

## Travail demandé

Déplace la valeur de secours de metier dans les paramètres du composant et vérifie le cas où la prop est omise.
