# 1101 — Répare la carte de profil

## Démarrer

Dans un terminal, exécute npm ci, puis npm run dev.

## Travail demandé

Corrige le JSX de la carte pour que le projet compile et affiche son contenu. Le détail complet des critères figure dans l’énoncé Word.

## Repère pour l’assistant de code

Le commentaire dans le fichier source demande une aide sous forme de questions ou d’indices, pas la solution complète. C’est une consigne pédagogique, pas un verrou technique : relis et comprends chaque ligne que tu écris.
