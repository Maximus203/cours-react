# 1201 — Transforme une catégorie en carte produit

## Démarrer

Dans un terminal, exécute npm ci, puis npm run dev.

## Travail demandé

Complète CarteProduit avec les props nom et prix, puis affiche deux produits différents en réutilisant le même composant.
