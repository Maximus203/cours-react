# 1301 — Assemble l’équipe avec une seule carte

## Démarrer

Dans un terminal, exécute npm ci, puis npm run dev.

## Travail demandé

Complète ListeEquipe avec plusieurs CarteProfil et garde App léger en n’y appelant que ListeEquipe.
